# Parkinson's Disease Detection

A Machine Learning project to detect Parkinson's Disease from voice measurements using voice features.

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![Scikit-learn](https://img.shields.io/badge/Scikit--learn-ML-orange)
![GUI](https://img.shields.io/badge/GUI-Tkinter-green)

## 📌 About
This project uses Machine Learning to classify whether a person has Parkinson's Disease based on voice measurement data from the UCI Parkinson's dataset.

## 🛠️ Tech Stack
- **Language**: Python
- **Libraries**: Scikit-learn, Pandas, NumPy, Tkinter
- **Model**: Random Forest Classifier

## 📂 Dataset
- `parkinsons.csv` - UCI Parkinson's Dataset
- Features: MDVP:Fo, MDVP:Fhi, MDVP:Flo, Jitter, Shimmer, etc.

## 🚀 How to Run
1. Install dependencies:   pip install -r requirements.txt
2.    python train_model.py
3.   python gui_app.py

## 📊 Results
- Achieved **~85% accuracy** on test data
- Includes data preprocessing, model training, and evaluation

## ⚠️ Disclaimer
> This project is for **educational purposes only**. It is **not a medical diagnostic tool**. Always consult a qualified medical professional for clinical diagnosis.
